# Advanced Password Generator 🔐

A Python-based password generator application that creates strong and secure random passwords.

## Features

- Generate custom length passwords
- Choose uppercase, lowercase, numbers and symbols
- Password strength checker
- Save generated passwords with timestamp
- Object-Oriented Programming implementation

## Technologies Used

- Python
- Random Module
- String Module
- File Handling
- OOP Concepts

## How to Run

1. Clone this repository

2. Run:

python password_generator.py
